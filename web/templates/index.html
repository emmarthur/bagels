    Help

    About this puzzle

    A secret {{ num_digits }}-digit number is chosen with no repeated digits. It can start with zero. Each guess must be exactly {{ num_digits }} digits. You may repeat a digit in a guess, but the secret never does.

    How to read a clue

    You get one word per digit that appears in the secret. The words are sorted alphabetically, so their order does not tell you which slot was right. If the secret were 248 and you guessed 843, the clue would be Fermi Pico: the 4 is in the right place, and the 8 is in the number but not in that place.

    How to use it

    1. Type a {{ num_digits }}-digit guess and press Check guess.
    2. Use the clue list to narrow the next guess. You have {{ max_guesses }} tries.
    3. After a win or a loss, New number starts another round. The answer is shown only when the round ends.
